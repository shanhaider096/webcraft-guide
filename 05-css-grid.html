CSS Grid Explained With Simple Examples

A practical, beginner-friendly guide from WebCraft Guide.

Introduction

CSS Grid is a two-dimensional layout system that works with rows and columns. It is useful for article cards, galleries, dashboards, and structured page sections.

Create a Grid

Set display:grid on a container and define columns with grid-template-columns. Flexible units such as fr can help distribute available space.

Use Gap

The gap property controls space between rows and columns. It often produces cleaner layouts than adding individual margins to every card.

Responsive Grids

A grid can change from several columns to fewer columns on smaller screens. Test the layout at narrow widths to make sure cards remain readable.

Grid or Flexbox?

Grid is often convenient for two-dimensional layouts, while Flexbox is often simpler for one-dimensional rows or columns. They can also be combined in the same project.

Conclusion

Build a small card gallery to practice Grid. Once columns, rows, and gaps make sense, more complex layouts become much easier.
